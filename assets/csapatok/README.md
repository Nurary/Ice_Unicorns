# Ellenfél-logók

Ezt a mappát a bajnoksági frissítés tölti fel automatikusan az MJSZ-től
kapott csapatlogókkal (lásd `scripts/logok.mjs`).

Ha egy csapatnak az MJSZ-nél nincs logója, ide kézzel is be lehet tenni egy
képet. A fájl neve a csapat neve ékezetek nélkül, kisbetűvel, kötőjelekkel,
például `Kárpáti Farkasok` → `karpati-farkasok.png` (png, jpg, webp vagy svg).
A következő frissítéstől ez a kép látszik az oldalon.

A logók az oldalon kör alakú keretben jelennek meg. Ezért a kép legyen
négyzetes, átlátszó hátterű, és a tartalma férjen bele a négyzetbe írt
körbe – különben a sarkai (széles logónál a két vége) levágódnak.

Ha az MJSZ-nél lecserélték egy csapat logóját, töröld innen a régit, és a
következő frissítés letölti az újat.
